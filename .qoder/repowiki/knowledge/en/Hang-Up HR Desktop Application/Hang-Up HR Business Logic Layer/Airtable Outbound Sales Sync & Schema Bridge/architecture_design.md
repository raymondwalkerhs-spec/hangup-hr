Five cooperating leaf files form a thin outbound integration over the raw Airtable REST API (no npm dependency):
- `airtable-client.js` is the HTTP transport: reads `AIRTABLE_API_KEY`/`AIRTABLE_PAT`, `AIRTABLE_BASE_ID`, `AIRTABLE_TABLE_NAME` from env, caches the table schema via `/v0/meta/bases/:id/tables` for 10 min, and exposes CRUD helpers (`findRecordByField`, `findAllRecordsByField`, `listAllRecords`, `createRecord`, `updateRecord`, `deleteRecord`, `deleteRecordsBatch`) plus `prepareFields` which normalizes values against the cached schema (select choices, multipleAttachments, numbers, collaborator stripping).
- `airtable-canonical-columns.js` drives schema provisioning by reading the canonical header row from `Asset/MLA AIRTABLE SHOULD BE LIKE THIS.csv`, merging it with `PORTAL_EXTRA_COLUMNS` and attachment columns from `sales-attachment-import-config`, producing `allProvisionFields()` used to create missing columns.
- `airtable-sales-field-map.js` owns the canonical column ↔ `form_data` key mapping (`CSV_TO_FORM`, `EXTRA_FORM_TO_AIRTABLE`, `AIRTABLE_FIELD_OVERRIDES`), value formatters (`formatDateForAirtable`, `formatDateTimeForAirtable`, `reverseMapUnit`, `formatTeamForAirtable`, `reverseMapDevice`), and the main `buildSaleFieldsForAirtable(sale, employees)` builder that also derives `Price` / `Price tier` and resolves employee names by id.
- `airtable-sales-sync.js` is the orchestrator: debounced `scheduleSaleSync` (deduped via `pendingTimers` + `inflight` set), loads employees and attachments in parallel, builds fields through the map, then upserts via `resolveAirtableRecordId` (first checks `sale.airtableRecordId`, then looks up by `Portal Sale ID`, auto-deletes duplicates) and persists sync metadata on the sale row.
- `airtable-attachment-parser.js` is a standalone parser for Airtable CSV export cells of the form `file.mp3 (https://...)`, reused by import code.

Dependency direction is one-way: sync → field-map → client; canonical-columns is independent configuration. Attachment resolution goes through `sale-attachment-storage.createAirtableSyncUrl` for Supabase-hosted files or falls back to Dropbox links.
