Four independent CommonJS modules with no internal cross-imports — each file is a self-contained utility barrel exported via `module.exports`. `payroll-gates.js` is the only gatekeeper: it calls into `./hrms-repo` (offboarding, clearance, equipment) and `./employee-status` to decide whether an employee's payslip can be approved or blocked. `bonus-guards.js` mirrors the same offboarding check but throws errors to prevent adding bonuses after departure. `commission-tiers.js` is stateless math over a `minSales`/`bonusAmount` tier list. `month-profile.js` owns the shape of a month's payroll profile (status enum, transport eligibility default from `TRANSPORT_ELIGIBLE_FROM_MONTH`, salary override + raise resolution) and is consumed by higher-level payroll builders. Dependency direction is strictly inward toward `hrms-repo` and `employee-status`; nothing in this module is imported by other business-logic modules except as pure functions.
