Local dev requires `credentials/service-account.json` (Google service account) and `.env` (copied from `.env.example` if missing); CI skips native rebuilds via `SKIP_NATIVE_REBUILD=1`. Windows builds run `./scripts/build.ps1 [portable|all]`, macOS runs `./scripts/build-macos.sh`, then publish with `./scripts/publish-github-release.ps1 [-IncludeFull -IncludeExtras -MultiPatch]`. Migrations are applied via `node scripts/apply-pending-migrations.js` using either `SUPABASE_ACCESS_TOKEN` (Management API) or `SUPABASE_DB_PASSWORD` (direct Postgres).
