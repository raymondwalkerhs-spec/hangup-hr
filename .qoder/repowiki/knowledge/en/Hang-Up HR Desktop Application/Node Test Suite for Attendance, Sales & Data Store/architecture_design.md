Flat collection of Node.js `node:test` suites (one per feature area) under `test/`, each file requiring the corresponding production module from `../lib/...` via CommonJS `require`. There is no shared test harness or fixture loader — every test file independently imports `node:test` and `node:assert/strict`, constructs minimal input objects inline, and asserts on return values. Files map one-to-one with domain concerns: `attendance-employment.test.js`, `attendance-fp-protection.test.js`, `attendance-import-route.test.js`, `attendance-persistence.test.js`, `attendance-supabase-path.test.js`, `attendance-validation.test.js`, `sales-working-day.test.js`, and `store-mutation-lock.test.js`.
